SYSTEM SPECIFICATIONS

Engineered for technical reliability.

How Auto Job automates complex career forms without triggering security walls or losing applicant context.

01

Formula-Aware Spreadsheet Ingestion

Extracts targets directly from Excel =HYPERLINK() formulas, resolves enterprise redirection tracking links, and deduplicates past applications automatically.

02

Multi-ATS Adapter Cascade

Universal layout heuristics for Greenhouse, Lever, Ashby, Workable, and Keka. Handles nested frame switches, dynamic select fields, and file upload triggers seamlessly.

03

Bring-Your-Own-Key (BYOK) Isolation

Operates entirely using your personal free Google Gemini API key. Zero shared server bottlenecks, zero telemetry, and 100% private to your local environment.

SECURITY & PRIVACY

Bring-Your-Own-Key (BYOK) Architecture

Why Auto Job requires your own free Gemini API key, and how this architecture guarantees zero cost and zero rate limits.

Generous Free Google Tier

Google AI Studio provides every standard Gmail account with 15 requests per minute and 1,000,000 tokens per day at zero cost. No credit card is required.

Zero Rate-Limit Collisions

Sharing a single developer key across thousands of users causes immediate API throttling. Your personal key gives you a dedicated, unthrottled line.

Strict Local Storage

Your API key is saved exclusively in your local data_folder/secrets.yaml file. It is never transmitted to any external server, database, or analytics tracker.
